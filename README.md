# استودیو مهارت — GitHub Pages

وب‌سایت فارسی و واکنش‌گرا برای فهرست‌کردن و پخش ویدیوهای مهارتی. اطلاعات ویدیوها از فایل `data/videos.json` خوانده می‌شود.

## فایل‌های پروژه
- `index.html`: صفحه اصلی
- `assets/style.css`: ظاهر واکنش‌گرا
- `assets/app.js`: جست‌وجو، فیلترها و پخش‌کننده
- `data/videos.json`: کاتالوگ ویدیوها

## فعال‌سازی GitHub Pages
1. وارد **Settings → Pages** این مخزن شو.
2. در **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
3. Branch را `main` و پوشه را `/(root)` انتخاب کن و Save بزن.
4. چند دقیقه صبر کن تا نشانی سایت در همان صفحه ظاهر شود.

## افزودن ویدیو
در آرایه `videos` در فایل `data/videos.json` یک شیء جدید اضافه کن. فیلدهای مهم:
- `id`: شناسه یکتا
- `title`: عنوان ویدیو
- `description`: توضیح
- `teacher`: نام مدرس
- `category`: دسته‌بندی
- `duration`: مدت بر حسب ثانیه
- `date`: تاریخ با قالب `YYYY-MM-DD`
- `thumbnail`: نشانی عمومی تصویر بندانگشتی (اختیاری)
- `videoUrl`: لینک مستقیم ویدیوی قابل پخش در مرورگر

**توجه:** ویدیوی داخل داده‌های فعلی فقط نمونه است؛ لینک `example.com` واقعی نیست و باید پیش از انتشار عمومی جایگزین شود. لینک صفحه دانلود ممکن است در پخش‌کننده کار نکند؛ لینک باید مستقیماً به فایل ویدیویی برسد.

## نکات
- فایل ویدیوها را در این مخزن قرار نده؛ فقط لینک آن‌ها را در کاتالوگ ثبت کن.
- بعد از هر تغییر در JSON، معتبر بودن ساختار JSON را بررسی کن.
- پخش را روی گوشی و اینترنت همراه آزمایش کن و نسخه پشتیبان مستقل از فایل‌های ویدیویی نگه دار.
- این نسخه پنل مدیریت، حساب کاربری یا آمار بازدید ندارد؛ برای تغییر فهرست باید فایل JSON را ویرایش و commit کنی.
